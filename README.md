# CoSPADE

**Behavior-Grounded Spatial Generation and Evaluation for Human–Robot Co-Performance**

面向人机共演的行为驱动空间生成与评价。融合建筑先验、本地计算与模型 API 生成候选布局，通过行为仿真和评价筛选获得优质布局，再积累需求与布局集合配对的数据，用于端到端生成模型微调。
